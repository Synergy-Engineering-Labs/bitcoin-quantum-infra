# Galaxy Bitcoin Quantum Readiness Initiative — Project Scope

## Project

**Bitcoin Post-Quantum Infrastructure (BPQI)** is open-source quantum-resistant infrastructure for Bitcoin built with Aegis as its post-quantum cryptographic dependency.

## Why the work is bounded

The project does not depend on inventing a new post-quantum signature scheme or replacing Bitcoin's core economic architecture. Standardized post-quantum signatures, Bitcoin upgrade mechanisms, and the Aegis cryptographic substrate already exist. The funded program focuses on integration, deterministic specification, public testing, independent assurance, and deployment readiness.

## Primary funded activities

Grant funding is expected to support:

1. independent cryptographic/security audit;
2. remediation and auditor retesting;
3. standards-conformance and applicable formal validation work;
4. Bitcoin Core integration;
5. Aegis-BTC consensus profile and reference specification;
6. wallet, descriptor, and PSBT integration;
7. migration tooling;
8. signet/regtest infrastructure;
9. adversarial performance and denial-of-service testing;
10. public vectors, benchmarks, interoperability tooling, and documentation.

## In-kind contribution

Synergy Engineering Labs contributes the existing Aegis technology and intends to authorize defined Bitcoin use of Aegis without licensing fees or royalties under a separate Bitcoin-specific license instrument.

## Public goods

The Bitcoin-specific implementation, test infrastructure, protocol specifications, migration tooling, and technical documentation funded through the project are intended to be open source.
