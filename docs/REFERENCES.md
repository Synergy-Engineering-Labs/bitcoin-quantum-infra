# Technical References

The BPQI design is expected to track the following primary specifications and projects as they evolve:

- BIP 141 — Segregated Witness (Consensus layer)
- BIP 174 — Partially Signed Bitcoin Transaction Format
- BIP 340 — Schnorr Signatures for secp256k1
- BIP 341 — Taproot
- BIP 342 — Validation of Taproot Scripts
- BIP 360 — Pay-to-Merkle-Root (draft)
- BIP 380 — Output Script Descriptors General Operation
- Bitcoin Core PSBT documentation
- NIST FIPS 204 — ML-DSA
- NIST FIPS 205 — SLH-DSA
- NIST post-quantum standardization materials for FN-DSA/FIPS 206 status

Normative BPQI behavior must pin exact revisions where consensus behavior depends on an external specification.
