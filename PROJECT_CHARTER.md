# BPQI Project Charter

## Mission

Deliver open-source, independently reviewable quantum-resistant infrastructure for Bitcoin using Aegis as the post-quantum cryptographic dependency.

## Engineering principles

- Bitcoin-native consensus semantics.
- Deterministic verification.
- Bounded parsing and resource accounting.
- Standards-based initial cryptography.
- Public interoperability evidence.
- Independent security review.
- Open Bitcoin-facing implementation.
- Clear separation between public BPQI code and proprietary Aegis internals.

## Non-goals

BPQI is not:

- a new blockchain;
- a Bitcoin replacement;
- an altcoin;
- a change to Bitcoin monetary policy;
- a replacement for proof of work;
- a claim that legacy UTXOs become protected without migration;
- a mechanism for silently changing Bitcoin consensus through Aegis configuration.
