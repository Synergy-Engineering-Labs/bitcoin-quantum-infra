# BPQI Signet Demonstration

This directory will provide scripts and configuration for a reproducible public demonstration in which developers can:

1. create a post-quantum key;
2. construct a quantum-resistant Bitcoin output;
3. fund the output;
4. construct a spend;
5. sign through the Aegis-BTC dependency;
6. broadcast the transaction;
7. validate the post-quantum signature; and
8. independently reproduce the result with the published vectors and reference implementation.
